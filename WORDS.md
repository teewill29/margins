# WORDS

Where every exercise's content comes from and the rules for drawing it. The goal: prompts that are surprising but always writable. A random dictionary draw gives you "procurement, ontology, wistfully". These rules make that impossible.

Everything here is static JSON in `src/data/`, generated by `npm run bank` from source lists in `scripts/bank/`. No network, no paid API.

## 1. Source lists (you write these in Phase 2 and 3)

Write the source lists yourself, as plain files in `scripts/bank/`. Rules for every list:
- **Original only.** No lines, titles or phrases taken from real songs, poems or books.
- **Concrete over abstract.** If you can't picture it, hear it or hold it, it doesn't go in the main banks.
- **Everyday words.** A word a 14-year-old knows. No jargon, no SAT words.
- **No song clichés** outside the abstract slot and the dice banned list: love, heart, baby, tonight, forever, fire, rain, soul, dream, broken, alone, feel, sky, eyes, night, light, world, stars, angel, shine, tears, goodbye, cry, kiss, hold, touch, crazy, wild, free, rise, fly, fall, lost, home, burn out.
  - Exception: some of these are fine as concrete nouns in context (`rain gutter` is fine, `rain` alone isn't).

## 2. Word bank (`src/data/words.json`)

### Entry shape
```ts
type Pos = 'noun' | 'verb' | 'texture' | 'place' | 'abstract';
interface WordEntry {
  w: string;          // lowercase base form: "swallow", "headlights"
  pos: Pos;
  conc: 1 | 2 | 3 | 4 | 5;   // concreteness: 5 = you can hold it, 1 = pure idea
  common: 1 | 2 | 3 | 4 | 5; // 5 = everyday, 1 = rare
  syl: number;        // syllables, from the CMU dictionary, else the `syllable` package
  worlds: string[];   // 1 or 2 world ids from the list below; [] allowed
  rhyme: string;      // rhyme key, computed by the build script
}
```

`texture` means a word that brings a surface, material or condition, used as an adjective or a noun: rust, static, velvet, gravel, sunburnt, damp, chrome.

### Target sizes
| pos | count | conc | examples |
|---|---|---|---|
| noun | 1,200 | 4–5 | porch, shovel, headlights, envelope, ankle, quarter |
| verb | 500 | 3–5 (physical actions) | borrow, swallow, burn, fold, sweep, idle |
| texture | 300 | 3–5 | rust, static, gravel, chrome, damp |
| place | 200 | 4–5 | cathedral, laundromat, overpass, bleachers |
| abstract | 150 | 1–2.5 | mercy, debt, patience, rumor, luck |

### Worlds
Each word gets 0, 1 or 2 of these ids. Aim for at least 60 nouns per world.

`road`, `kitchen`, `church`, `small-town`, `weather`, `body`, `night`, `coast`, `winter`, `school`, `job-site`, `bar`, `bedroom`, `garage`, `farm`, `city`, `motel`, `hospital`

### Rhyme key
Computed by `npm run bank` from `cmu-pronouncing-dictionary`: the phonemes from the last stressed vowel to the end, stress digits removed. "porch" → `AO R CH`, "torch" → `AO R CH` (they rhyme). Words not in the dictionary: the last 3 letters, prefixed with `~` so they only clash with each other.

### Build script checks (fail the build if any break)
- No duplicate `w`.
- Every `pos` meets its target count within 10%.
- `conc` ranges above hold per pos.
- Every world has at least 60 nouns.
- No word in the cliché list appears outside `abstract`.

## 3. Seeded randomness
- `rng = mulberry32(hashString(seed))`, both in `src/lib/random.ts`. `hashString` is cyrb53 or xmur3. Never use `Math.random()` for any draw.
- A page's seed is set once when the page is created: `page:<pageId>`.
- Daily grid seed: `margins-daily-YYYY-MM-DD`, using the local date.
- Same seed + same inputs → same output, always. This is what lets bandmates get the same daily grid.

## 4. The word grid draw

### Recipe (16 words)
| slot | count | conc rule | common rule |
|---|---|---|---|
| noun | 8 | ≥ 4 | ≥ 3 |
| verb | 4 | ≥ 3 | ≥ 3 |
| texture | 2 | ≥ 3 | ≥ 2 |
| place | 1 | ≥ 4 | ≥ 2 |
| abstract | 1 | ≤ 2 | ≥ 3 |

So a grid never has more than one abstract word.

### Theme pull by difficulty
| difficulty | themed slots | feel |
|---|---|---|
| Loose | 12 | the words already share a world |
| Medium (default) | 10 | mostly one world, a few strays |
| Wild | 4 | a puzzle |

### Algorithm: `drawGrid({ seed, difficulty, locked, stats })`
1. `rng` from `seed`.
2. Pick one world at random (equal weight).
3. Build the 16 slots from the recipe. Locked words fill slots of their own pos first. If a pos is already full from locks, the extra locked word takes a noun slot, then a verb slot.
4. Shuffle the unfilled slots with `rng` and mark the first N as themed (N from the difficulty table, minus any locked words that belong to the world).
5. Fill each unfilled slot in this order: abstract, place, textures, verbs, nouns. For each slot, the candidates are bank words that:
   - match the slot's pos, conc rule and common rule
   - are in the chosen world, if the slot is themed
   - aren't banned
   - aren't already in the grid
   - don't share a root with a word in the grid (use `rootOf` from DETECTION.md: no `burn` and `burned`)
   - don't share a rhyme key with a word in the grid
   If a themed slot has no candidates, drop the world filter for that slot. If there are still none, drop the rhyme rule.
6. Pick from the candidates by weight: `weight = max(0.1, 0.5 ** swaps) * (favorite ? 2 : 1)`. `swaps` and `favorite` come from the word's stats.
7. Shuffle all 16 into display order with `rng`. Locked words keep their grid cell.

### Daily grid
Same algorithm with `seed = margins-daily-YYYY-MM-DD`, difficulty Medium, no locks, and **no stats** (ignore bans, favorites and swap counts). That's what keeps it the same for everyone.

### Swaps, locks, bans
- 3 swaps per grid. A swap replaces one word with a single-slot draw: same pos, same themed status, seed `page:<id>:swap:<n>` where n counts swaps on that page. Increments the old word's `swaps` stat.
- Locked words stay through Shuffle and swaps. Lock state is stored on the page.
- Ban: sets `banned` in word stats. The word is excluded from every future draw. It isn't removed from grids that already exist.
- Shuffle: redraws all unlocked words with seed `page:<id>:shuffle:<n>`.

### Tests (write these first)
1. A grid has exactly 16 unique words.
2. Slot counts match the recipe: 8 noun, 4 verb, 2 texture, 1 place, 1 abstract (no locks).
3. At most 1 word has `conc` ≤ 2.
4. No two words share a rhyme key (with a test bank where that's possible).
5. No two words share a root.
6. Loose → at least 12 words in the chosen world; Medium → at least 10; Wild → at least 4 (with a test bank big enough).
7. Same seed + inputs → identical grid, in identical order. Different seed → different grid.
8. A banned word never appears in 1,000 draws.
9. Locked words survive Shuffle in the same cells.
10. A 4th swap is refused.
11. A word with `swaps: 3` is drawn about 1/8 as often as one with `swaps: 0` over 10,000 draws from a small test bank (within 25%).
12. Daily grid ignores bans and favorites: two different stats objects give the same daily grid.
13. With a tiny world that has 2 nouns, a Loose grid still fills all 16 slots (fallback works).

## 5. Word ladder
8 nouns and 8 verbs from the same bank, one world, Medium rules (6 themed per column). Same root, rhyme and ban rules. Each column shuffles on its own seed: `page:<id>:nouns:<n>` and `page:<id>:verbs:<n>`.

## 6. Other exercise banks

### Objects (`objects.json`, 300)
`{ text: "A motel ice bucket", worlds: ["motel"] }`
An everyday object plus a detail that places it. The detail is what makes it writable: "A church parking lot cone", "A dashboard air freshener", "Grandpa's tackle box", "A hospital vending machine". Every object must have a sound, smell or texture you can describe.

### Lines (`lines.json`, 150 first + 150 last)
`{ text: "The porch light's been on since June", kind: "first", mood: "ache", tense: "present" }`
- 4 to 10 words, one concrete image per line, no clichés.
- `mood`: `ache`, `restless`, `tender`, `bitter`, `funny`, `eerie`, `hopeful`, `numb`
- `tense`: `past`, `present`, `future`
- First lines open a scene. Last lines land one ("And I left the truck running").
- Draw: random, skipping the last 20 lines shown (stored in settings).
- My lines from Settings are mixed in at the same weight.

### Titles (`titles.json`, 200)
1 to 5 words, original, singable: "Quarter in My Shoe", "Static on the Porch", "Good Year for Ghosts". Same 20-line no-repeat rule.

### Constraint dice (`dice.json`)
- `pov` (7): I, We, You, He, She, They, "You, talking to an object"
- `tense` (4): Past, Present, Future, "Would" (conditional)
- `place` (100): specific and visual: "a gas station at 2 a.m.", "the back row of a wedding", "a flooded basement"
- `banned` (40): the cliché list in section 1, plus: "remember", "inside", "away", "never". Rolling a banned word bans it from the page (see SPEC).

### Character (`characters.json`)
- `names` (200): varied and real-sounding: Dale, Marisol, Tiny, June, Okafor, Bettina
- `age`: random integer 16 to 85
- `jobs` (150): specific: "works nights at a toll booth", "repossesses boats", "runs the snow cone stand"
- `wants` (100): "wants his daughter to call", "wants one more good season"
- `obstacles` (100): "keeps missing her", "the truck won't start", "already told everyone he quit"
- Rendered: `${name}, ${age}, ${job}. ${capitalize(want)}. ${capitalize(obstacle)}.` Pronouns: write wants and obstacles in a form that works for anyone ("keeps missing the call", not "his call"), or tag each name with pronouns and use `{they}` placeholders. Pick one approach and note it in the Progress log.

## 7. Learning from use
Word stats (DATA_MODEL.md) track `shown`, `used`, `swaps`, `banned`, `favorite`. Only `swaps`, `banned` and `favorite` affect draws, per section 4. `shown` and `used` are for a future "words you never use" view; record them now, don't build the view.
